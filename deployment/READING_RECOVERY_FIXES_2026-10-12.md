## 实现

- 可选 observation_ids 不再是搜索/阅读的硬性执行前提。合法引用保留，无法解析的引用单独归档；只按精确 source_id 关联真实阅读记录，不猜测科学证据。
- 背景角色默认使用科研主模型。搜索适配器独立读取 AI_SCIENTIST_SEARCH_ACQUISITION_MODEL / LLM_SEARCH_MODEL；显式项目角色配置仍优先，不静默覆盖用户选择。
- 公共读取支持文本型 PDF、页数与字符截断标记；保留 HTTPS、公共 IP、重定向复查、下载限制。扫描件/加密文档明确拒绝，不声称 OCR。HTML 排除 nav/footer 等导航噪声；query 可定位缓存中的文字并返回真实读取范围。
- 相同失败 URL 不重复下载，除非模型给出 retry_reason。失败站点和错误进入后续上下文，提示换源；不把整个域永久封锁。
- 搜索重复来源合并标题/摘要元数据，避免先遇到裸 URL 后丢弃后续带标题的引用信息。仍没有标题时继续标明待核对，不能编造论文名称。
- finish 缺少评估时，自动从实际已读材料生成 ReadingNotes：自然语言阶段回答 + 资料判断。模型选择短段落编号，程序复制原文；保留来源、局限和摘录核对，未满足条件的来源不自动采用。
- 阅读笔记不再默认逐条串行独立审核。`assessment_mode=reading_note`、`semantic_review.status=not_requested` 明确区别于已审核解释；前端显示提示，采用后的证据也带该状态与局限。采用来源不是认证所有科学主张。显式 assess_source 仍保留严格核查，正式报告可按需独立核查。
- 笔记的来源/摘录字段有问题时允许一次有界修正；失败时仍保留阶段回答并停下，不强判研究成功。旧审核与修改前笔记保留历史。
- 连续无进展时优先整理已有阅读，而非直接要求用户修工具参数。
- 前端新增“停止继续检索，整理已有资料”、阶段回答下载与已读来源链接。选择该操作后 reading_only 阻止恢复流程擅自回到搜索。
- 暂停提示如实解释背景阶段会在动作边界停下，不把在途 API 请求声称为取消。
- 真实测试又发现缺失 purpose 字段导致整体拒收，现提供中性内部默认值；单对象数组外壳可无损解包，多个对象或缺科学字段仍需正常校验。
- 摘录核对仅放宽空白/排版标点，不放宽数字、比较关系或语义。科学夸大仍需模型依据原文纠正。

# 固定科研流程中的工具调用

## 本次调整

产品只有原有阶段式科研流程。并行的“自主研究工作台”不再作为操作入口，
旧记录只读保留；旧项目和旧代码审批不会被自动转换成新流程的审批或成果。

工具服务于阶段，不取代阶段验收：

| 阶段 | 实际能力 | 必须满足的条件 |
| --- | --- | --- |
| 背景研究 | Qwen 提议网页检索或 Crossref 论文检索 | 默认先由人审核检索方案 |
| 候选资料审查后 | 逐页读取公开 HTTPS 原文，保存文本、最终地址、校验和及失败原因 | 只读取选定来源；默认由人选择 |
| 证据整理 | Qwen 提取内容，程序逐字匹配该来源的摘录 | 元数据或 DOI 本身不能代替新来源的原文核对 |
| 等待执行 | 根据已审批的问题、设计、分析计划及实际上传数据生成 Python | 科研方案已批准，计算功能和隔离环境可用 |
| 执行 | 获批代码进入无网络的 Linux 隔离环境 | 单独批准准确的代码方案版本；输入改变需重新生成 |
| 数据分析 | 整理真实指标、程序审计、独立计算判断和局限 | 不跳过本阶段，不把执行成功当科研证明 |
| 独立复审及综合 | 原有审查、人工审批和报告流程 | 不伪造正面结论，不自动替人批准 |

计算最多两轮科学分析，每轮最多两次程序错误修复。修复不能改变获批方法、
数据、指标和停止条件。需要外部测量、额外资源或缺失数据时必须说明限制。
固定阻尼示例仍使用其明确标识的确定性执行器；新问题的生成代码不依赖项目 ID。

## 人类前端复现

1. 按原部署方式启动后端与 Streamlit；通用计算需安装 bubblewrap 和
   `computation-requirements.txt`，配置 `AI_SCIENTIST_ENABLE_COMPUTATION=1`。
2. 打开本地 `http://127.0.0.1:8501/`，新建问题，保留默认辅助证据审查模式。
   如要真实计算，取消“仅规划”；上传真实数据，或明确说明是数学模拟。
3. 点击“运行下一阶段”。顶部始终显示原始问题，当前阶段和自然语言进度在下方。
4. 到“检索方案审查”时，查看每条检索式选择的工具；修改后的新检索式默认网页检索。
   人工批准后继续运行，再选择保留的来源。原文无法访问或引文不匹配不会被伪装成验证成功。
5. 按原流程形成假设、方法、研究设计、分析方案，处理独立审查意见并人工批准。
6. 到执行阶段点击“生成计算方案”。阅读方法、数据、指标、检查、停止条件，展开代码审阅。
   只有本人勾选确认并点击“批准并执行计算”才会执行；无需手动选择专用 executor。
7. 查看实际指标表、局限及产物。若建议第二轮，须重新生成并审批；缺数据就先补充。
8. 继续“数据分析 → 独立复审 → 人工批准 → 科学综合”，查看最终报告。
   只生成计划、只计算成功、独立复审通过是不同状态，不可混为完成。

历史自主工作台在折叠区提供台账下载和报告预览。没有删除其历史数据，
也没有将其计算结果冒充为固定流程已通过的结果。

## 验证和边界

```bash
RUN_NAMESPACE_TESTS=1 .venv/bin/python -m pytest -q
```

回归测试包含真实 Linux 隔离执行，以及使用明确模型替身的阶段、审批、
来源核对和前端测试。它们不等价于真实 Qwen 端到端科研成功。

在线来源读取目前支持有限大小的 HTML/文本/JSON/XML，不绕过付费墙、登录、
验证码或禁止访问；PDF 可走上传解析。Crossref 返回书目信息而非完整论文。
逐字摘录匹配并不证明摘录支持所有推论；相关性、方法适用性、科学有效性仍须审查。
已有来源推荐仍包含启发式评分，本次没有实现任意浏览器操作或无限制自主工具循环。

本版本是固定工作流中的受控工具集成，不宣称已解决“任意问题的通用科研”。
